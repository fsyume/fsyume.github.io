# EP1 入坑准备：下载、注册、选服、捏脸

「FF14 萌新入门」第一期。这一期把"入坑门槛"一次解决：确认要不要玩、装游戏、注册账号、选大区服务器、把角色建出来，最后告诉你首次上线该干嘛，避免刚进游戏一脸懵就退坑。

> 系列目录 / 视频链接：[FF14 萌新入门教程](/ffxiv/FF14萌新入门教程.md)

## 这游戏是什么

《最终幻想14》（Final Fantasy XIV，简称 FF14 / 狒狒14）是 SQUARE ENIX 的 MMORPG。和很多"上来就开打"的网游不同，它以**主线剧情**为骨架，一个角色就能练全部职业，整体节奏更像"单机大作 + 联机副本"。

先记两个词：
- **光之战士**：对玩家角色的称呼
- **豆芽**：新手标志。首次进本时，队友能一眼看出你是新人

## 国服现状：值不值得现在入坑

- 国服由盛趣运营，**自 7.4 版本起已与国际服更新同步**，不用担心"落后好几个大版本"
- 付费是**点卡 / 月卡双计费**，没有强制消费
- 常有**萌新招待 / 招募**活动，老玩家带新人有额外奖励，可以找朋友"带一带"
- 建议先用免费试玩，确定喜欢再正式激活

> 🖼️ 待补图：国服官网首页 / 版本同步公告

## 平台与账号

- **国服**：主要通过官网下载 PC 客户端（或 WeGame 入口）游玩，本文以国服为例
- **国际服**：官网购买 + Steam / PS4 / PS5 / Xbox 等平台，另有繁中服务器，收费方式与国服不同
- 账号安全：**别把账号借人、别买卖账号或金币**，被盗或被封得不偿失

## 免费试玩能玩到什么

国服新账号未正式激活即可试玩，**30 小时免费时长（进入游戏后 14 天内有效）**：

| 项目 | 试玩限制 |
| --- | --- |
| 等级 | 全职业可练到 **80 级**（到顶后不再获得经验，仍可继续打 80 级以下副本） |
| 金钱 | 最多持有 **300,000 金币** |
| 角色 | 每个服务器最多 1 个，每个大区合计最多 8 个 |
| 社交 | 不能用呼喊 / 喊话 / 悄悄话；不能加入部队、不能建立通讯贝 |
| 交易 | 不能用市场布告板购买、不能与他人交易、不能用莫古邮件、不能雇雇员 |
| 组队 | 不能主动建小队 / 招募，但**能加入他人小队**，也能用任务搜索器进副本 |
| 高难 / PvP | 不能打绝境战、不能玩 PvP |

> 试玩到期后 90 天内不正式激活，试玩账号数据会被清除；试玩期间激活则解除全部限制。

## 下载安装与登录

1. 到官网注册账号、下载客户端
2. 安装并登录，首次会下载较大体积资源，建议预留足够的磁盘空间
3. 登录界面依次选择**大区 → 服务器**，进入游戏

> 🖼️ 待补图：官网下载页 / 登录选择大区界面

## 大区与服务器怎么选

国服目前有 **4 个大区**：**陆行鸟、莫古力、猫小胖、豆豆柴**。

- **同一大区内的服务器之间可以自由「跨界传送」**；跨大区暂时不能自由来回（官方在推进中）。所以**大区基本等于"你以后和朋友一起玩的范围"**
- 选服原则：
  1. 优先和朋友在同一个服务器 / 大区
  2. 喜欢热闹选人口中等偏上的服务器；不想挤可以选相对清闲的
  3. 部分服务器会临时"限制创建角色"，创建前先在官网或登录界面确认
- 拿不定主意就选朋友在的、或口碑稳定的老服，后期成本最低

> 🖼️ 待补图：各大区服务器列表 / 角色创建入口

## 创建角色：种族、外观、命名

- **种族**：主要影响外观和极少量初始属性 / 身高，**对战斗强度几乎没有影响**，按喜好选即可
- **外观 / 捏脸**：创建时可调很多细节，后期还能用道具"美容 / 重塑"
- **命名**：名字会长期跟着你，起个自己顺眼的；不满意可以后续改名（可能收费）
- **先选什么职业？** 创建时选的只是初始职业。FF14 里**一个角色可以转职练全部职业**，所以不用纠结，选个眼缘好的就行

> 🖼️ 待补图：创建角色界面 / 种族选择

## 首登后该做什么（防劝退清单）

刚进游戏别乱点，按这个顺序走：

1. 跟着**新手引导**做完操作教学
2. 打开**任务日志**，接并推进**主线任务**（剧情主线）
3. 熟悉**以太之光（传送点）**，先把主城里的点亮
4. 顺手把**聊天框 / 键位**按自己习惯调一调
5. 别怕落后：**主线进度才是核心**，等级和装备都会自然跟上

## 常见坑

- ❌ 花钱买金币 / 代练：**封号风险**，千万别碰
- ❌ 把账号借给陌生人
- ⚠️ 免费试玩有社交与交易限制，介意的话可以先小成本正式激活
- ⚠️ 别把"打怪升级"当唯一目标，FF14 的主线剧情才是本体
